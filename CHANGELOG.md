# Changelog

## 0.3.0

- Add compact per-run JSON and Markdown indexes with track provenance and coverage gaps.
- Add offline indexing, bounded reading plans, coverage status and validated report acceptance for existing transcript collections.
- Preserve source exports while creating unique index and batch outputs; expose structured JSON results for agents.

## 0.2.0

- Reframe the product around caption-derived text corpora for LLMs and agents.
- Make the modified srt_fix component, exact upstream revision, license scope and
  Codex/GPT-assisted development visible in the README and NOTICE.
- Add whole public-channel input and nested upload-tab enumeration; default
  collection processing remains uncapped, with an optional explicit video limit.
- Generate combined JSON and Markdown from a selected run. Add a text-only profile
  that avoids repeated transcript bodies while retaining source provenance.
- Preserve auto/manual/translation and processing provenance in normalized merges.
- Add structured final JSON reports and deterministic Python launcher discovery.
- Add reproducible, commit-bound source release archives with manifests/checksums.

## 0.1.0

Initial independent import of the local download/merge workflow, derived cleaner,
Windows runtime fixes, atomic outputs, hash-based resume and agent setup guide.
Published as source commits; no versioned release asset was created for 0.1.0.
